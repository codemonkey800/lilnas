Design system · Category Standard

Every component, every state

Quiet, conventional, consistent: dark violet-tinted surfaces, hairline borders, 6–8px corners, soft status pills and one accent. This page is built from the shared kit in docs/designs/mockup-kit, so it is the same markup every app's mockups use. The rules live in DESIGN.md; the component specs in docs/designs/components.md.
