Backup

What a signed-in person sees from then on, one screen per state of their backup. Each has a status badge, one headline, and at most one accent button: Download, Open my photos, Sign in again or Try again. Only a live backup wears the pulsing dot. Each state is a frame showing 1280 and 390 side by side.
