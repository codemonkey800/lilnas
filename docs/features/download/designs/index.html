UI mockups — round 1

Nine screens against the Ultraviolet system, most with their own desktop/mobile switch (the nav-bar field's reference doesn't need one — it renders identically everywhere): the homepage's quick access and recently added, that nav-bar field's full state and flow reference, a dedicated search page for movies and shows, movie and show detail pages, the unified gallery, a video's own detail page, the downloads-activity feed, and the admin dashboard. The video, movie, and show detail pages each carry their own download lifecycle — progress, pause/cancel, queued, failed — inline, with no separate status page to navigate to.

Home Library overview, quick access, and recently added. Nav-bar search The entry-point field on every page — every state, and the full flow to a download or a search. Search Movie and show discovery's dedicated home — title, year, cast, or genre, with filters. Unified gallery Videos, movies and shows in one filterable grid. Movie detail Trailer, cast, and cover art — plus every download state, queued to failed. Show detail Seasons and episodes — download, delete, replace, or track progress live. Video detail Cover art, source link, and the download's progress, right on the page. Downloads activity Every download in flight, across every user, live. Admin dashboard System metrics, unmasked attribution, top downloaders, and the audit log.

Tokens and components reused from docs/designs/preview/index.html — no new colours, radii, type sizes or motion curves introduced here. Poster art is a CSS placeholder (same fallback idea as the real app's MediaResultCard), so each file below is fully self-contained: its own inline styles, no shared file to keep in sync, and no external image requests. There's no JavaScript at all — the desktop/mobile switch on each screen (all but the nav-bar field's own reference, which needs only one) is a native radio input plus :has(), since a sandboxed preview viewer can never run a script this file provides for itself. Open any of them directly; nothing else needs to load first.
