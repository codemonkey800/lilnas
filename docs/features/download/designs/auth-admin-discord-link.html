Edit access modal

edit-access-modal.tsx

The new "Discord account" field sits below Services. On Save, the value is diffed against the snapshot the modal opened with — the same pattern the Services grid already uses (accessSnapshotRef): unchanged → no call at all; changed to a new value → linkDiscordAccount (this is also how a first-time link happens, and how an existing one is replaced); cleared to empty → unlinkDiscordAccount. A snowflake already linked to someone else comes back from the server as a normal modal error line, same as any other save failure.
