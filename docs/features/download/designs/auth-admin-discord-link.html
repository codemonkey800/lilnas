Discord account linking

Plan 017-discord-attribution-and-account-linking.md, task B3. An admin links a lilnas person to a Discord snowflake so their tdr-bot downloads unify with their web history — but never by typing a handle or an ID. Both sides of the pairing are observed, not typed: lilnas people the first time they sign into the web app, Discord accounts the first time someone runs /download. Linking is a pick-one-from-each-list action, keyed on the immutable snowflake, so a Discord rename never breaks an existing link. This is apps/auth's admin surface — a separate app from apps/download, with its own design system (design-tokens.css), which this file reproduces rather than force-fitting into the download app's Tailwind mockup pipeline.
